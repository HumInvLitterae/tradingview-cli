This release adds the first Desktop-free symbol evidence packet for agent
workflows. It also records snapshot workflow guidance and opt-in live contract
evidence while keeping broader chart-backed and daemon-like surfaces deferred.

## Highlights

- Added `tv snapshot <SYMBOL>`, a Desktop-free JSON command that combines
  scanner-backed quote data, symbol info, and scanner-backed fundamentals into
  one evidence packet.
- Preserved per-section `quote`, `info`, and `fundamentals` success/error
  details so downstream agents can see partial failures without losing
  successful evidence.
- Reused existing `tv fundamentals --group` and `--field` selection for the
  snapshot fundamentals section.
- Added an opt-in ignored Rust live smoke for the `tv snapshot <SYMBOL>` JSON
  contract.
- Updated workflow docs and runtime skills so `snapshot` is the first-pass
  one-symbol Desktop-free read, while `observe chart` remains the
  Desktop-backed time-window observation command.

## Behavior Notes

- `tv snapshot <SYMBOL>` does not connect to TradingView Desktop, switch the
  visible chart symbol, capture screenshots, start JSONL observation, or call
  the lab-gated `tv bars` path.
- Snapshot output is a single JSON envelope, not a batch, watch, JSONL, daemon,
  or chart-backed command.
- Chart and visual follow-up remain explicit next steps through commands such
  as `tv readiness`, `tv observe chart`, and `tv screenshot`.
- Fundamentals values in snapshot are raw TradingView scanner values. The CLI
  does not infer timezone, before/after-market meaning, publication-code
  meaning, or investment significance from them.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
