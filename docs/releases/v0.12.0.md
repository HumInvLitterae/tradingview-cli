This release improves `tv compare <SYMBOL>...` as a contract-stable evidence
follow-up surface. It adds additive readback metadata for coverage state and
missing evidence routing while keeping the Desktop-free comparison packet and
raw per-symbol `items[]` as the evidence source.

## Highlights

- Added `summary.coverage_status` to compare payloads with `complete`,
  `partial`, and `blocked` evidence coverage states.
- Fixed the shipped follow-up hint vocabulary for compare items, including
  `snapshot`, `observe_chart`, `chart_quote`, and `screenshot`.
- Documented `summary.field_coverage` count semantics and `requested_index`
  as the requested-order join authority.
- Added `items[].missing_evidence[]` so downstream tools can route missing
  quote, info, and fundamentals evidence to explicit follow-up surfaces.
- Preserved existing `items[]`, section evidence, section errors,
  `missing_summary`, `summary.resolved_symbols[]`, source metadata, top-level
  counts, and `next_action_hints`.

## Behavior Notes

- `tv compare <SYMBOL>...` remains Desktop-free. It does not connect to
  TradingView Desktop, switch the visible chart, capture screenshots, start
  JSONL observation, or call the lab-gated `tv bars` path.
- Coverage status and missing-evidence metadata are readback helpers. They do
  not rank, score, recommend, or infer trading actions.
- Follow-up hints and missing-evidence suggestions name available evidence
  surfaces. They are not priority rankings or recommendations.
- Raw `items[]` remains the evidence source. Use metadata to join, scan, and
  identify gaps, then inspect item sections before drawing conclusions.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
