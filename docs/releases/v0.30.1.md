`v0.30.1` is a dependency-only patch release over `v0.30.0`.

## Changed

- Updated the locked CLI/runtime dependency graph to compatible releases of
  `clap`/`clap_derive`, `serde_json`, `hyper`, `libc`, and `tokio`, aligning
  direct workspace constraints where applicable.
- Preserved the `v0.30.0` command surface, JSON contracts, Replay screenshot
  attachment behavior, runtime skills, and package layout.

## Boundaries

This patch adds no command, option, output field, source fallback, retry,
timeout, foreground behavior, shared session, broker, or workflow change.
Production source is unchanged. Build-input changes are limited to compatible
workspace dependency constraints, their `Cargo.lock` selections, and the
workspace patch version.

## Validation

The release is validated with the complete Rust workspace baseline, strict
Clippy, a locked release build, four pinned Node.js `24.18.0` production-
JavaScript contracts, public hygiene, and the explicit 46-file package check.
