This release focuses on chart-backed workflow maturity. It adds an explicit
Desktop-backed chart compare workflow, expands event readback across multiple
symbols, lets Replay step logs attach selected-chart OHLCV summaries on
request, and adds Strategy Tester panel screenshots as visual evidence.

## Highlights

- Added `tv chart compare <SYMBOL>...` for small finalist sets where the
  selected TradingView Desktop chart feed is the source under review. The
  command returns `contract_version: "chart_compare.v1"`, ordered item status,
  before / after chart context, and restore readback.
- Added `tv events compare <SYMBOL>...` for ordered multi-symbol earnings and
  dividend evidence from the Desktop-free scanner fundamentals source. The
  command returns `contract_version: "events_compare.v1"` and preserves
  item-level success / error status.
- Added `tv replay log --attach-ohlcv-summary` with optional `--ohlcv-count
  <N>` so bounded Replay step logs can explicitly attach selected-chart OHLCV
  summary evidence with
  `contract_version: "replay_log_ohlcv_summary_attachment.v1"`.
- Added `tv screenshot --region strategy --output <PATH>` for non-mutating
  visual evidence of the visible Strategy Tester panel.

## Behavior Notes

- `tv compare` and `tv watch compare` remain Desktop-free scanner-backed
  workflows. Use `tv chart compare` only when selected-chart evidence itself
  is the point of the check.
- `tv events compare` is not a full event calendar. It reshapes scanner
  fundamentals earnings and dividends fields and does not infer timezone,
  confirmed status, ranking, recommendation, or trading meaning.
- Replay OHLCV summary attachment is opt-in. Attachment failures are reported
  separately from Replay step failures and do not turn the step log into a
  stable Replay export.
- `tv screenshot --region strategy` captures visual evidence only. Structured
  Strategy Tester metrics remain in `tv data strategy`, `tv data trades`, and
  `tv data equity`.
- The pre-release architecture audit found no release-blocking source-boundary
  issue and no larger refactor requirement before this release.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, runtime-oriented skills, and the English and

repository docs remain excluded.
