`v0.28.0` strengthens TradingView Desktop mutation safety and adds bounded
Desktop-free scanner breadth to the Rust-native `tv` CLI.

## Highlights

- Pine saved-script operations now verify the intended Save-bound script
  identity instead of treating source replacement alone as success. Pine
  Editor selection ignores hidden stale Monaco instances, scopes saved-script
  menu selection to the linked popup, and fails closed on ambiguity.
- `tv pine save` uses Command+S on macOS and Control+S on Windows/Linux, and
  reports success only after explicit saved-and-clean readback. Pine
  `get`/`set`/`new` Runtime failures expose fixed public-safe stage metadata
  rather than raw exception or payload details.
- `tv indicator add` now uses one current chart-owned inserter path, resolves
  one exact public metainfo entry, preserves JavaScript-safe keyed inputs,
  awaits insertion, and verifies the first same-ID readback.
- `tv launch` removes inherited `ELECTRON_RUN_AS_NODE` from direct spawn and
  the normal macOS system launcher while preserving unrelated environment
  values. Successful macOS fallback is no longer overridden by the original
  direct child's state.
- `tv draw shape` accepts paired `--price3` and `--time3` for native
  `parallel_channel` creation. Success requires exactly one new entity plus
  verified native identity and three-point readback.
- `tv scanner scan` adds explicit `--offset` reads and bounded aggregation with
  `--max-results` and optional `--page-size`. Aggregation retains the 100-row
  request cap, stays within 10,000 rows and 100 requests, reports sequential
  drift, deduplicates in first-seen order, and never returns partial success
  after a failed or incomplete page.

## Boundaries

Scanner pagination remains a Desktop-free scanner read. Pine, indicator,
drawing, and launch operations remain explicit TradingView Desktop workflows.
The CLI does not automatically mix these sources or add ranking, scoring,
recommendations, or trading decisions.

Windows MSIX package-identity launch, selected-chart finite-`f64` right-offset
restoration, width-derived drawing geometry, other three-point drawing types,
and indicator search remain deferred.

## Validation

The completion and architecture audit found no release-blocking architecture
issue or required pre-release refactor. Four separately pinned Node.js
`24.18.0` gates execute the generated study-value, Pine open/save, indicator
insertion, and three-point drawing JavaScript contracts before release builds.
Ordinary Cargo tests remain Node-independent.

Release archives continue to use the explicit eight-skill runtime allowlist and
exclude development-only skills, plans, and local project ledgers.
