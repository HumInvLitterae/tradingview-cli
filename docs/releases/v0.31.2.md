`v0.31.2` is a dependency-only patch over `v0.31.1`.

## Changed

- Updated compatible direct and transitive dependencies used by existing CLI
  parsing, asynchronous execution, HTTP/2, TLS, WebSocket, Unicode URL parsing,
  procedural-macro, Wasm support, and native build paths.
- Direct workspace constraints now select `clap` 4.6.6,
  `futures-util` 0.3.34, and `thiserror` 2.0.20.

## Boundaries

This patch adds no command, option, output field, source, fallback, retry,
reconnect, timeout change, shared session, broker, workflow, or package-layout
change. Production source is unchanged.

The patch does not claim a performance or reliability improvement. It ships
compatible dependency maintenance under the existing command, error, and
package contracts.

## Validation

The release is validated with the complete Rust workspace suite and doctests,
strict Clippy, a locked release build, four pinned Node.js production-
JavaScript contracts, public hygiene, workflow parsing, and the explicit
46-file package check. Native release jobs remain the final Linux, macOS Intel,
macOS arm64, and Windows proof for the updated TLS and native build graph.
