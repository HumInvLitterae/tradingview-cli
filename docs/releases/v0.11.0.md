This release improves `tv compare <SYMBOL>...` as a downstream-safe comparison
contract. It adds additive readback metadata that helps agents and wrapper
tools keep compare output aligned with their original symbol lists while still
preserving raw per-symbol `items[]` as the evidence source.

## Highlights

- Added `data.contract_version: "compare.v1"` to successful `tv compare`
  payloads as a command-local contract marker.
- Added stable zero-based `requested_index` values to each compare item and to
  each `summary.resolved_symbols[]` entry.
- Added per-item `follow_up_hints[]` with machine-readable follow-up surfaces
  such as `snapshot`, `observe_chart`, `chart_quote`, and `screenshot`.
- Added `summary.field_coverage` with quote, info, fundamentals, earnings, and
  dividends missing/ok count readback.
- Preserved existing `items[]`, section errors, top-level counts,
  `summary.resolved_symbols[]`, `errors[]`, source metadata, and
  `next_action_hints`.

## Behavior Notes

- `tv compare <SYMBOL>...` remains Desktop-free. It does not connect to
  TradingView Desktop, switch the visible chart, capture screenshots, start
  JSONL observation, or call the lab-gated `tv bars` path.
- The new metadata is for readback and schema guarding. It does not rank,
  score, recommend, or infer trading actions.
- Raw `items[]` remains the evidence source. Use metadata to join, scan, and
  identify gaps, then inspect item sections before drawing conclusions.
- Follow-up hints name available evidence surfaces; they are not priority
  rankings or recommendations.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
