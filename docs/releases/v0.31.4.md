`v0.31.4` refreshes dependencies and reorganizes the agent guidance shipped
with each release archive. CLI commands and JSON contracts are unchanged.

## Runtime guidance

The archive now contains six runtime skills with self-contained references:
`market-data`, `chart-analysis`, `pine-develop`, `replay-practice`,
`screener-workflow`, and `strategy-report`.

Update prompts or agent configuration that explicitly name
`market-data-interpretation`, `multi-symbol-scan`, or `screener-result-analysis`
to use `market-data`. The consolidated skill routes symbol/data discovery,
historical bars, screening and comparison to the existing CLI commands.

Packaged guides now organize workflows by purpose. Contributor-only `continuity`
and `release-prep` remain outside release archives; the repository's generic
commit/discovery skill wrappers are retired. Commit conventions live in the
development guide.

## Dependencies and packaging

- Updated direct constraints to `clap` 4.6.7 and `reqwest` 0.13.5, with compatible
  locked updates across HTTP/TLS, compression, platform and build support.
- Added package validation for the exact runtime skill allowlist, both skill
  roots and agent-guide parity, transitive local Markdown references, and
  references escaping the package. CI also tests the validator and stages a
  placeholder package independently of native binary builds.

## Scope

This is a maintenance patch. It adds no MCP client, new command, authentication,
source fallback, retry/reconnect behavior or Desktop operation. The official
MCP client is a separate later feature. Dependency refreshes retain the existing
public contracts and are checked through the release validation baseline.
