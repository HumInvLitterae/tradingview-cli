This release improves `tv` as an agent-operated TradingView toolkit across two
lanes: Desktop-free market data reads and Desktop-backed readiness diagnostics.

## Highlights

- Added experimental `tv bars <SYMBOL> --timeframe <TIMEFRAME> --count <N>`
  behind `TV_EXPERIMENTAL_BARS=1` for bounded Desktop-free historical bars.
- Added Desktop-free `tv fundamentals <SYMBOL>` for scanner-backed fundamental
  fields, including earnings-related fields when TradingView returns them.
- Added repeatable `tv fundamentals --group earnings|valuation|dividends|financials`
  bundles so callers can request useful field groups without memorizing scanner
  field names.
- Improved Desktop readiness diagnostics across `status`, `tab list`, `state`,
  chart-source quote, and OHLCV failure details.
- Clarified runtime guidance so portable agents use structured `tv`
  diagnostics and screenshots first; Computer Use remains an optional Codex app
  aid, not a general runtime assumption.
- Recorded a TradingView Desktop capability gap audit to prioritize future read
  surfaces by operator value instead of broad Desktop parity.

## Behavior Notes

- `tv bars` is lab-gated and experimental. It uses an undocumented TradingView
  WebSocket chart-session path, requires an exchange-qualified symbol such as
  `NASDAQ:AAPL`, and does not replace chart-backed `tv ohlcv`.
- `tv fundamentals` remains a Desktop-free scanner REST read. Values are
  returned as TradingView scanner values under `field_values`; the CLI does not
  infer timezone, before/after-market meaning, or investment conclusions.
- Credential-free scanner reads remain useful for screening, but they are not a
  realtime entitlement guarantee.
- Desktop-backed commands continue to prefer structured readiness diagnostics
  over hidden retries or visual fallback.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
