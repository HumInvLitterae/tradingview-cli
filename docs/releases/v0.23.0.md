This release turns the `v0.22` evidence readback work into more explicit
Desktop-backed workflows while preserving source boundaries. It adds a
selected-chart export command, a bounded Replay step log, and planning records
for chart-backed compare and standalone event surfaces.

## Highlights

- Added `tv export chart-bars --from <UNIX_SECONDS> --to <UNIX_SECONDS>`, a
  narrow Desktop-backed selected-chart export workflow. It returns
  `export_chart_bars.v1` diagnostics for requested visible range, range
  operation, selected-chart context, returned bars range, and range-match
  status.
- Added `tv replay log --steps <N>`, a bounded Desktop-backed JSONL workflow
  for recording Replay state transitions. It emits `replay_step_log.v1`
  readiness, step, and summary events.
- Planned chart-backed compare boundaries while keeping `tv compare` and
  `tv watch compare` as Desktop-free scanner-backed workflows.
- Planned standalone `tv events` feasibility while keeping current earnings
  and dividends reads as scanner-backed fundamentals fields.

## Behavior Notes

- `tv export chart-bars` is explicit selected-chart evidence. It is not a
  hidden fallback for Desktop-free `tv bars --from/--to`.
- `tv replay log` records Replay workflow evidence. It does not start or stop
  Replay, export OHLCV bars, capture screenshots, rank symbols, or make
  trading recommendations.
- Chart-backed compare is not a stable command in this release.
- There is no stable standalone `tv events` command yet. Event-like earnings
  and dividends data remains under scanner-backed fundamentals reads.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, runtime-oriented skills, and the English and
Japanese getting-started docs. Development-only skills and the broader
repository docs remain excluded.

## Validation

The release-prep checks cover workspace metadata, release package staging, a
locked release build, staged archive contents, Rust formatting, Clippy,
workspace tests, version readback, diff hygiene, and public-doc safety scans.
