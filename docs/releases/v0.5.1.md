This patch release fixes a remaining stale-data risk in chart-backed symbol
quotes and adds an opt-in maintainer smoke for repeated live chart switches.

## Fixed

- Hardened `tv quote <SYMBOL> --source chart` so success now requires the
  requested symbol, observed quote symbol, current chart symbol, bar
  availability, changed bar signature after a switch, and consecutive stable
  requested-symbol samples.
- Kept `--source auto` chart-first behavior, while preserving the rule that
  scanner fallback is not used after a chart mutation has already begun and
  chart readiness fails.
- Kept `tv quote <SYMBOL>` default scanner-backed behavior and `tv quotes`
  batch reads unchanged.

## Tests And Docs

- Added an opt-in ignored Rust integration smoke for maintainers:
  `TV_LIVE_CHART_QUOTE_SMOKE=1 cargo test -p tradingview-cli --test live_chart_quote -- --ignored --nocapture`.
- Added the `v0.6.0` roadmap draft and command source taxonomy docs so
  Desktop-free reads, Desktop-backed reads, operations, hybrid commands, and
  experimental commands are easier to distinguish.

## Behavior Notes

- `--source chart` prioritizes correctness over speed and may take a few
  seconds for symbol-targeted reads.
- Downstream agents should not add manual sleep or double-call workarounds for
  chart-source quote reads. If the CLI cannot prove readiness, it returns a
  structured readiness error.
- The live endurance smoke is not part of CI because it requires a logged-in
  TradingView Desktop session with CDP enabled.

## Packaging

Release archives continue to include the `tv` binary, README, changelog,
license, user-facing agent guides, and runtime-oriented skills only.
