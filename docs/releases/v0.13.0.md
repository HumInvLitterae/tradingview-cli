This release clarifies source and session boundaries for quote workflows and
adds an explicit Desktop-backed quote-data source. It helps agents distinguish
scanner-backed quote freshness, selected-chart main-series data, visible
after-hours research evidence, and bounded WebSocket quote-data readback
without mixing those sources.

## Highlights

- Added `session_boundary` metadata to chart-source quote payloads so
  `tv quote <SYMBOL> --source chart` states that selected chart main-series
  data does not provide scanner-style extended-hours fields.
- Added `tv quote <SYMBOL> --source quote-data` as an explicit
  Desktop-backed WebSocket quote-data readback source for fields such as
  `qsd.rtc`.
- Added opt-in ignored live smokes for quote-session, visible after-hours
  panel, WebSocket correlation, widget-store, and quote-data source evidence.
- Added `tv snapshot <SYMBOL>` contract metadata, including
  `contract_version: "snapshot.v1"`, coverage summary, missing-evidence
  readback, and machine-readable follow-up hints.
- Clarified stable follow-up vocabulary shared by `tv compare` and
  `tv snapshot`, keeping `chart_quote` as the canonical chart-feed quote
  hint.
- Clarified `tv quote` and `tv quotes` help so scanner-backed reads are not
  mistaken for guaranteed realtime data and direct users to `time`,
  `update_mode`, and `delay_seconds`.

## Behavior Notes

- Scanner-backed `tv quote <SYMBOL>` and `tv quotes <SYMBOL>...` remain
  Desktop-free scanner REST reads. They can be delayed; inspect freshness
  metadata when timing matters.
- `tv quote <SYMBOL> --source chart` remains selected-chart main-series data.
  It does not include scanner `extended_hours` values and does not read
  Desktop quote-data WebSocket fields.
- `tv quote <SYMBOL> --source quote-data` is explicit, Desktop-backed, and
  bounded. It is not part of `--source auto`, does not switch symbols, and
  returns structured unavailable details when no matching quote-data frame
  arrives.
- After-hours and quote-session research evidence remains source-labeled.
  Premarket-specific quote-data evidence and automatic source mixing are
  deferred.
- Snapshot metadata and follow-up hints are readback helpers. They do not
  rank, score, recommend, or infer trading actions.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
