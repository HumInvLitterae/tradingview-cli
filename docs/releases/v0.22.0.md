This release makes existing evidence surfaces easier to connect in agent and
human workflows without hiding where data came from. It adds a bounded watch
workflow, selected-chart and Replay feasibility readback, and clearer
follow-up hints while keeping source mixing, ranking, recommendations, daemon
behavior, and stable export commands out of scope.

## Highlights

- Added `tv watch compare <SYMBOL>...`, a bounded Desktop-free JSONL workflow
  for watching a known candidate set with scanner-backed quote evidence. It
  emits `watch_compare.v1` readiness, sample, heartbeat, and summary events.
- Added selected-chart export evidence readback to `tv ohlcv` and `tv range`
  so agents can inspect selected-chart context, visible-range diagnostics, and
  returned bar ranges without treating selected-chart reads as `tv bars`
  fallbacks.
- Added Replay feasibility readback to `tv replay ...` commands. `status` is
  readable as a Desktop-backed Replay state read, while start, step, stop,
  autoplay, and trade are marked as state-changing Replay operations.
- Clarified `snapshot.v1` and `compare.v1` `follow_up_hints[]` with source
  metadata, evidence roles, mutating status, and `auto_execute: false`.

## Behavior Notes

- `tv watch compare` is a short-window observation workflow. It is not a
  daemon, realtime entitlement guarantee, ranking engine, trading signal, or
  selected-chart feed.
- Selected-chart export evidence readback is diagnostic. It helps evaluate
  whether future explicit export workflows are safe, but it does not create a
  stable export command.
- Replay readback is diagnostic and stateful. Replay controls can change the
  selected chart's Replay state and are not a replacement for Desktop-free
  historical `tv bars --from --to`.
- Follow-up hints are advisory. The CLI does not automatically run follow-up
  commands, switch sources, take screenshots, start observations, rank
  symbols, or make trading recommendations.
