This release makes two source-boundary improvements for agent workflows: explicit quote-data reads can now succeed during regular session when TradingView quote-data exposes `lp` instead of `rtc`, and browserless `tv bars` is now a stable Desktop-free historical bars command.

## Highlights

- Added `quote_data.price_readback` to `tv quote <SYMBOL> --source quote-data`.
- Quote-data still prefers `qsd.v.rtc` when available, but matching non-null `qsd.v.lp` can now succeed as `price_readback.kind: "regular_last"`.
- Added `source_availability.price_readback_observed` and wait-summary counters so agents can distinguish source availability from price absence.
- Stabilized `tv bars <EXCHANGE:SYMBOL>` as a Desktop-free historical bars read without `TV_EXPERIMENTAL_BARS=1`.
- Added the stable `bars.v1` contract and `source: "tradingview_bars_ws"` metadata to `tv bars` success and structured failure details.

## Behavior Notes

- `quote-data` remains an explicit Desktop-backed WebSocket source. It is not added to `--source auto` and is not merged with scanner quote, chart-source quote, or scanner `extended_hours`.
- `price_readback.kind: "rtc"` and `price_readback.kind: "regular_last"` are source-labeled evidence readbacks, not ranking, scoring, recommendation, or trading signals.
- `tv bars` is bounded historical OHLCV evidence. It does not guarantee realtime or entitlement status, and it is separate from selected-chart `tv ohlcv`.
- Scanner-backed `tv quote <SYMBOL>` and `tv quotes <SYMBOL>...` remain Desktop-free scanner REST reads. They can be delayed; inspect freshness metadata when timing matters.

## Packaging

Release archives include the `tv` binary, README, changelog, license, user-facing agent guides, and runtime-oriented skills only. Development-only skills remain excluded.
