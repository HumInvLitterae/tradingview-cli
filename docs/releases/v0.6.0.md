This release improves `tv` as an observation-first TradingView CLI with clearer
source metadata, bounded stream controls, Desktop readiness checks, and cleaner
public / packaged documentation.

## Highlights

- Added bounded observation controls to Desktop-backed `tv stream ...`
  commands: `--duration-ms`, `--max-events`, and `--heartbeat-ms`.
- Added stream sample / heartbeat metadata so JSONL consumers can distinguish
  changed samples from heartbeat events and identify Desktop-backed source
  requirements.
- Added `tv readiness` as a non-mutating Desktop-backed read for CDP target
  selection, chart API readiness, OHLCV bar readiness, and next action hints.
- Added source taxonomy metadata to screenshots, core Desktop-backed reads,
  chart-source quote payloads, and Desktop-free market / scanner reads.
- Added root `tv --version` / `tv -V` support for release archive and local
  binary sanity checks.
- Cleaned README, contributor guides, and packaged runtime agent guidance so
  each document has a clearer audience and role.

## Behavior Notes

- `tv stream ...` remains Desktop-backed and still runs indefinitely when no
  bounded options are provided. With `--duration-ms` or `--max-events`, it can
  be used as a finite JSONL observation producer for downstream agents.
- `tv readiness` does not mutate TradingView state and does not capture a
  screenshot. It reports whether the current Desktop / CDP / chart target /
  bars state is ready and suggests portable next steps.
- `tv screenshot` is treated as Desktop-backed visual evidence. It does not
  mutate TradingView state, but it does write the requested local output file.
- Desktop-free scanner and market reads now expose source metadata, but their
  price freshness still depends on TradingView's data source and entitlement
  behavior.
- `tv bars` remains lab-gated behind `TV_EXPERIMENTAL_BARS=1` and is not a
  stable replacement for chart-backed `tv ohlcv`.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
