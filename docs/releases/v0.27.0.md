`v0.27.0` improves current-build chart and evidence workflows in the
Rust-native TradingView CLI.

## Highlights

- Strategy Tester metrics, trades, and equity now use current strategy metadata
  and report-aware selection. Their shared public-safe `strategy_context`
  distinguishes selected, hidden, unready, missing, and ambiguous states
  without opening Strategy Tester or changing study visibility.
- `tv range --from/--to` can boundedly request older history from the selected
  chart's main series before applying a visible range. Finite request and time
  limits, endpoint coverage, market-gap handling, and viewport diagnostics make
  partial outcomes explicit.
- `tv screenshot --wait-for-render` optionally waits for stable selected-chart
  and requested-region evidence before capture. Immediate capture remains the
  default, and a wait timeout does not create or overwrite an image.
- `tv values` and `tv stream values` now include public-safe study-instance
  identity, compact inputs, visibility, and conservative study kind. Optional
  identity failures do not remove existing value rows, and stream dedupe reacts
  to identity or visibility changes.

## Source and mutation boundaries

Selected-chart history paging remains a TradingView Desktop operation on the
current chart's main series. It does not fall back to Desktop-free `tv bars`,
OHLCV export, Replay, scanner data, or another source. Strategy report reads
remain non-mutating, and screenshot readiness is opt-in.

Indicator and strategy search was investigated but is not shipped in this
release because positive result readiness was not reproducible across dialog
states. This release does not add automatic source mixing, ranking, scoring,
recommendations, trading decisions, a daemon, dashboard, MCP server, or another
binary.

## Validation

The completion and architecture audit found no release blocker or required
pre-release refactor, and independent review reported no findings. Ordinary
Cargo tests remain Rust-only. A separate required contract gate executes the
generated study-value JavaScript helper with Node.js `24.18.0` before release
builds. Release archives continue to use the explicit runtime-skill allowlist;
development-only skills and planning documents are not packaged.
