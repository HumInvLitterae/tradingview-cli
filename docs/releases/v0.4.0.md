This release focuses on Desktop-free market data reads and clearer data-source
boundaries. It keeps account mutations and UI automation conservative while
making quick symbol checks, scanner reads, and Rust library reuse more useful.

## Highlights

- Added extended-hours quote data for Desktop-free scanner-backed
  `tv quote <SYMBOL>` reads, including premarket and postmarket fields when
  TradingView returns them.
- Added confirmed premarket and postmarket scanner columns to
  `tv scanner scan --columns ...`.
- Added `tv scanner metainfo` for Desktop-free scanner field discovery.
- Added ordered batch quote reads with `tv quotes <SYMBOL>...`.
- Added explicit quote source selection with
  `tv quote <SYMBOL> --source scanner|chart|auto`.
- Added scanner quote `time`, `update_mode`, and parsed `delay_seconds`
  metadata so delayed feed boundaries are visible in JSON payloads.
- Added typed reusable read APIs and Rust documentation for the internal
  `tradingview-market` and `tradingview-scanner` crates.
- Added runtime skills for market-data source interpretation and
  scanner/Screener result analysis.

## Behavior Notes

- `tv quote <SYMBOL>` defaults to the Desktop-free scanner source for
  convenience.
- Use `tv quote <SYMBOL> --source chart` when the selected TradingView Desktop
  chart feed is required.
- Use `tv quote <SYMBOL> --source auto` for chart-first behavior with scanner
  fallback only when the chart path is unavailable before mutation.
- `tv quotes <SYMBOL>...` is scanner-backed and preserves input order in
  `items[]`.
- `tv ohlcv` remains a selected-chart command. Desktop-free historical bars are
  still a research candidate, not a stable command in this release.

## Packaging

Release archives continue to include the `tv` binary, README, changelog,
license, user-facing agent guides, and runtime-oriented skills only.
Development-only skills are intentionally excluded.

## Notes

- This project is not affiliated with TradingView Inc.
- Credential-free scanner price reads are useful for screening, but they are
  not a realtime entitlement guarantee. Exchange rules, TradingView feed
  selection, and market-data subscription state can affect freshness.
- The release does not add cookie/session import, login automation, an MCP
  server, trading bot workflow packs, or a stable Desktop-free historical bars
  command.
