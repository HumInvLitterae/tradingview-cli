`v0.26.0` is a robustness and I/O-correctness release for the Rust-native
TradingView CLI.

## Highlights

- JSON and JSONL output now handles a downstream consumer closing its pipe
  without a panic, duplicate error envelope, backtrace, or unnecessary follow-up
  polling.
- CDP events that arrive while a method response is pending are retained in a
  bounded FIFO queue, and response/event waits use absolute deadlines.
- Public HTTP, local CDP HTTP, CDP WebSocket, and browserless bars operations
  have explicit finite deadlines. Configured HTTP clients are reused within
  their owning operation without adding retries or automatic fallback.
- Bars heartbeat pong framing now uses a consistent declared payload length
  while retaining legacy receive compatibility.
- Market, Scanner, Pine, and CDP HTTP failures use consistent connection,
  timeout, remote-status, and payload classifications with public-safe details
  and stable exit codes.
- Bounded Desktop-free quote, compare, and event reads use at most four symbol
  operations at once while preserving input order and partial-result behavior.

## Reliability and project hygiene

- Cross-platform CDP and CLI connection-failure tests use controlled
  reconnect-capable loopback fixtures rather than released or fixed ports.
  Windows, Ubuntu, macOS, Clippy, Format, and both script-check jobs passed in
  the final CI run.
- Canonical Git history was sanitized of removed machine-specific path text,
  with release refs, assets, tags, and fresh-clone validation preserved.
  Existing-clone recovery guidance and retained rollback evidence remain
  explicit project-owner decisions.

## Boundaries

`tv` remains a single CLI with explicit Desktop-free and Desktop-backed source
boundaries. This release does not add automatic source mixing, quote-data
fallback, ranking, scoring, trading recommendations, a daemon, a dashboard, an
MCP server, or a new binary split.

The existing `tv chart compare`, `tv events compare`, Replay evidence
attachment, and Strategy Tester screenshot workflows retain their explicit
source and evidence boundaries.

## Validation

The final CI run passed all Windows, Ubuntu, macOS, Clippy, Format, and script
checks. Release archives continue to use the explicit runtime-skill allowlist;
development-only skills and contributor-only documentation are not packaged.
