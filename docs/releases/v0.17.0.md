This release matures browserless `tv bars <EXCHANGE:SYMBOL>` into a more
useful historical evidence surface for agents and downstream tools. The focus
is still bounded Desktop-free historical OHLCV reads, not realtime feeds,
source mixing, ranking, or recommendations.

## Highlights

- Added `summary` and `range` readback to `tv bars` success payloads.
- `summary` reports requested count, returned bar count, first/last time,
  ordering, count fulfillment, and coverage status before consumers parse raw
  `bars[]`.
- `range` reports timeframe, first/last time, and returned bar count as a
  compact historical coverage readback.
- Added `source_availability` and public-safe `wait_summary` diagnostics to
  `tv bars` success and structured failure details.
- No-bars, timeout, WebSocket close/read failure, and protocol error paths
  remain structured source diagnostics instead of empty success payloads.

## Behavior Notes

- `tv bars` remains a Desktop-free bounded historical bars read with
  `contract_version: "bars.v1"` and `source: "tradingview_bars_ws"`.
- `tv bars` is separate from selected-chart `tv ohlcv`, scanner quotes, chart
  quotes, explicit quote-data reads, and `tv stream ...` observation commands.
- `source_availability` and `wait_summary` describe bounded source behavior.
  They are not price evaluation, ranking, scoring, recommendation, or trading
  action evidence.
- This release does not add realtime multi-symbol feeds, watch / JSONL
  compare, chart-backed compare, quote-data auto fallback, automatic source
  mixing, standalone `tv events`, alternate binaries, an MCP server, daemon
  behavior, or trading bot workflows.

## Internal Cleanup

- Moved browserless bars implementation into the Desktop-free
  `tradingview-market` crate so CLI operations remain thin adapters.
- Split the market crate bars implementation into private validation,
  protocol, transport, payload, and type modules while preserving the public
  `tradingview_market::bars_symbol(...)` entrypoint.
- Split the large CLI contract integration test into command-family targets
  with shared helpers.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
