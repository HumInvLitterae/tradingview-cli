This patch release fixes a stale-data risk in chart-backed symbol quotes.

## Fixed

- Hardened `tv quote <SYMBOL> --source chart` so it waits for the selected
  TradingView Desktop chart bars to reflect the requested symbol before
  returning success.
- Added one bounded retry for chart quote readiness timeouts. If the chart still
  appears stale after the retry, the command now fails with a structured error
  instead of returning previous-symbol quote data.
- Preserved restore behavior after temporary chart symbol switches.
- Kept `tv quote <SYMBOL>` default scanner-backed behavior and `tv quotes`
  batch reads unchanged.

## Behavior Notes

- `--source chart` prioritizes correctness over speed and can take a few
  seconds for symbol-targeted reads.
- Downstream agents should not add their own sleep or double-call workaround
  for chart-source quote reads.
- `--source auto` remains chart-first, but it does not fall back to scanner data
  after a chart mutation has already begun and readiness fails.
