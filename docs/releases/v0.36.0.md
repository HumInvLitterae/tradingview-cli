`v0.36.0` checks saved Pine source before indicator-alert operations, repairs
Pine Editor opening, and rejects invalid bars-frame lengths without crashing.
It also adds offline descriptions of quote-data diagnostic requirements and
effects.

## Saved Pine source must match

Both `alert create-indicator --dry-run` and normal creation now read the selected
saved script revision and compare it with the supplied local source before any
alert operation. Only line-ending differences are accepted. Spaces, comments,
BOMs, and terminal-newline differences require the local and saved copies to be
aligned first.

A mismatch returns `validation` with `phase: saved_source_verification` and
`reason: source_mismatch`. Missing saved identity/version or unreadable source
returns `internal_api_unavailable`; the command no longer guesses version 1.0.
Previously, a preview could succeed without reading the saved source.

This check does not save or compile the script, add a chart study, or change
study inputs. Dry-run remains a live catalog/source read, not an offline check
or proof that an alert will be accepted. Matching text does not establish
compiled condition IDs, chart-study/input identity, or complete creation readback.
Successful output keeps its existing shape.

Condition discovery uses the same LF/CRLF/lone-CR interpretation. A comment
followed by lone CR no longer hides the next plot or changes its condition index.
Source line and column positions remain consistent across those line endings.

## Pine Editor and bars reliability

Pine commands now prefer the dedicated editor button when available. A legacy
widget API that still exists but no longer opens Pine therefore does not block
opening the editor. Existing saved-script binding checks remain in place.

Desktop-free `bars` now rejects frame lengths that overflow or end inside a
UTF-8 character through the existing protocol-error path instead of panicking.
Valid Unicode, heartbeat packets, and combined frames retain their behavior.

## Offline quote-data diagnostic guidance

```sh
tv spec diagnose quote-data
```

The spec describes the scanner reference request, Desktop dependency, observation
window, and blocked/unavailable outcomes. The spec command itself is offline.
Diagnostic acquisition, source routing, and recovery behavior are unchanged.

## Verification scope

The saved-source preflight passed bounded live dry-runs for matching text,
line-ending differences, and a deliberate mismatch. Pine Editor opening was
verified from a closed panel. New malformed-frame regressions use synthetic
WebSocket responses. Normal indicator-alert creation was not exercised again.

A bounded read-only chart run completed 40/40 reads without failure. These
observations do not establish a speedup, universal provider availability, or
performance on other charts. No retry, shared session, or new timeout policy
is introduced.
