This release makes `tv` more useful as an agent-ready observation producer. It
adds the first workflow-level observation command, improves opt-in live smoke
coverage for observation and lab bars paths, and rounds out scanner-backed
fundamentals field bundles.

## Highlights

- Added `tv observe chart`, a Desktop-backed JSONL observation workflow that
  emits readiness first, then selected-chart last-bar samples and heartbeats.
- Added opt-in ignored Rust live smokes for the `tv observe chart` JSONL
  contract and lab-gated `tv bars` JSON contract.
- Added `docs/observation-workflows.md` as a concise guide for choosing between
  Desktop-free screening, Desktop-backed chart observation, screenshots,
  experimental bars, and fundamentals reads.
- Enriched `tv fundamentals --group earnings|dividends` with additional
  scanner-metainfo-backed earnings and dividend fields, and allowed the same
  fields through explicit fundamentals fields and scanner scan columns.

## Behavior Notes

- `tv observe chart` is Desktop-backed and non-mutating. It does not switch
  symbols, activate tabs, capture screenshots, or change account/page state.
- `tv stream ...` remains compatible and lower level. Use it when a specific
  chart stream kind is needed directly.
- `tv bars` remains experimental and gated by `TV_EXPERIMENTAL_BARS=1`; it is
  still not a stable replacement for chart-backed `tv ohlcv`.
- The enriched fundamentals fields are raw TradingView scanner values. The CLI
  does not infer timezone, before/after-market meaning, publication-code
  meaning, or investment significance from them.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
