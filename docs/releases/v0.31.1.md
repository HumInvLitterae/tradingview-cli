`v0.31.1` is a dependency and documentation patch over `v0.31.0`.

## Changed

- Updated compatible locked versions of dependencies used by existing HTTP,
  TLS, WebSocket, URL parsing, and asynchronous runtime paths.
- Closed the published v0.31 planning state and corrected contributor guidance
  so agents resolve the current roadmap through the plan index instead of a
  fixed historical version.

## Boundaries

This patch adds no command, option, output field, source, fallback, retry,
reconnect, timeout change, shared session, broker, workflow, or package-layout
change. Direct dependency constraints and production source are unchanged.

The patch does not claim a performance or reliability improvement. It ships
compatible resolved dependency updates under the existing command and error
contracts.

## Validation

The release is validated with the complete Rust workspace suite and doctests,
strict Clippy, a locked release build, four pinned Node.js production-
JavaScript contracts, public hygiene, workflow parsing, and the explicit
46-file package check.
