This release improves `tv compare <SYMBOL>...` for downstream agent workflows.
It adds additive summary readback to the existing Desktop-free comparison
packet and clarifies when to use `quotes`, `compare`, `snapshot`, chart
observation, chart-source quote, and screenshots.

## Highlights

- Added `data.summary` to `tv compare <SYMBOL>...` with requested, resolved,
  error, per-section success, missing-value, and ordered resolved-symbol
  readback.
- Preserved the raw per-symbol `items[]` evidence shape. The summary is a
  scanability helper, not a replacement for evidence.
- Clarified workflow guidance so `tv compare` stays a Desktop-free
  multi-symbol evidence packet, `tv snapshot` remains one-symbol detail, and
  chart commands remain explicit follow-up reads.
- Recorded the pre-release completion and refactor audit for the v0.10 compare
  polish lane.

## Behavior Notes

- `tv compare <SYMBOL>...` remains Desktop-free. It does not connect to
  TradingView Desktop, switch the visible chart, capture screenshots, start
  JSONL observation, or call the lab-gated `tv bars` path.
- `compare.summary` is for readback and scanability. It does not rank, score,
  recommend, or infer trading actions.
- Use raw `items[]` and section-level evidence before drawing substantive
  conclusions or choosing follow-up commands.
- Chart and visual follow-up remain explicit through commands such as
  `tv snapshot`, `tv observe chart`, `tv quote --source chart`, and
  `tv screenshot`.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.

## Notes

- This project is not affiliated with TradingView Inc.
