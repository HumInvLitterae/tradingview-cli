This release matures existing Desktop-backed JSONL observation surfaces so
agents and downstream tools can read bounded observation events more safely.
The focus is `tv observe chart` and lower-level `tv stream ...`, not new
realtime feeds, watch loops, source mixing, ranking, or recommendations.

## Highlights

- Added command-local `contract_version` markers to `tv observe chart` and
  `tv stream ...` JSONL events.
- `tv observe chart` events now use `observe_chart.v1` and include
  `_observe: "chart"` for readiness, sample, heartbeat, and summary events.
- Lower-level `tv stream ...` sample, heartbeat, and summary events now use
  `stream.v1`.
- Bounded observation runs now emit a final `_event: "summary"` line with
  sample count, heartbeat count, elapsed time, bounded controls, and end
  reason.

## Behavior Notes

- `tv observe chart` remains a Desktop-backed selected-chart observation
  workflow. It does not switch symbols, activate tabs, capture screenshots, or
  read browserless historical bars.
- `tv stream ...` remains a lower-level selected-chart observation surface for
  specific stream kinds such as quote or bars.
- Summary events describe how the bounded observation window ended. They are
  not market-data samples and should not be treated as ranking,
  recommendation, or trading-action evidence.
- This release does not add realtime multi-symbol feeds, watch / JSONL
  compare, chart-backed compare, quote-data auto fallback, automatic source
  mixing, standalone `tv events`, alternate binaries, an MCP server, daemon
  behavior, or trading bot workflows.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.
