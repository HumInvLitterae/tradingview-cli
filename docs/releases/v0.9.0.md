This release adds Desktop-free multi-symbol comparison for agent workflows. It
also records live contract evidence for compare and keeps chart-source quote as
a single-symbol selected-chart follow-up rather than a realtime batch source.

## Highlights

- Added `tv compare <SYMBOL>...`, a Desktop-free JSON command that preserves
  input order and returns per-symbol quote, info, and default fundamentals
  evidence.
- Preserved section-level `quote`, `info`, and `fundamentals` success/error
  details so downstream agents can compare candidates without losing partial
  evidence.
- Added source metadata, missing-value summaries, compact section errors, and
  next-action hints in the comparison packet.
- Added an opt-in ignored Rust live smoke for the `tv compare <SYMBOL>...`
  JSON contract.
- Recorded chart-source quote concurrency evidence and kept chart-source quote
  out of multi-symbol comparison defaults.

## Behavior Notes

- `tv compare <SYMBOL>...` does not connect to TradingView Desktop, switch the
  visible chart symbol, capture screenshots, start JSONL observation, or call
  the lab-gated `tv bars` path.
- Compare output is a single JSON envelope, not a watch, JSONL, daemon,
  chart-backed, or realtime feed command.
- Compare is for evidence comparison, not ranking, scoring, buy/sell
  recommendations, or realtime entitlement guarantees.
- Chart and visual follow-up remain explicit next steps through commands such
  as `tv snapshot`, `tv observe chart`, `tv quote --source chart`, and
  `tv screenshot`.

## Packaging

Release archives include the `tv` binary, README, changelog, license,
user-facing agent guides, and runtime-oriented skills only. Development-only
skills remain excluded.

## Notes

- This project is not affiliated with TradingView Inc.
- This release does not add chart-backed compare sources, ranking or scoring
  options, watch/JSONL compare behavior, realtime multi-symbol feeds, stable
  browserless bars, standalone `tv events`, `tv diagnose`, alternate binaries,
  an MCP server, cookie/session import, login automation, or trading bot
  workflows.
