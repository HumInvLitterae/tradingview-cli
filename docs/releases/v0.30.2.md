`v0.30.2` is a focused performance and dependency patch over `v0.30.1`.

## Performance

- CDP screenshot payloads now use a SIMD-capable base64 decoder. Successful
  screenshot bytes, PNG output, regions, file behavior, and JSON responses are
  unchanged.

## Changed

- Updated compatible versions in the locked dependency graph, including build,
  CLI parsing, platform, TLS type, procedural macro, and asynchronous utility
  dependencies.
- Replaced the sole direct `base64` dependency with `base64-simd`; the decoder
  remains an internal implementation detail.

## Boundaries

This patch adds no command, option, output field, source fallback, retry,
timeout, foreground behavior, shared session, broker, or package-layout
change. It does not claim a measured end-to-end screenshot speedup: Desktop
rendering, CDP transfer, PNG generation, image processing, and file I/O remain
outside the base64-only measurement.

## Validation

The release is validated with focused screenshot decoder regression tests, the
complete Rust workspace baseline, strict Clippy, a locked release build, four
pinned Node.js `24.18.0` production-JavaScript contracts, public hygiene, and
the explicit 46-file package check. Native release jobs cover Linux, macOS
Intel, macOS arm64, and Windows.
