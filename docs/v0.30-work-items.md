# v0.30.0 ordered work inventory

This inventory turns `docs/v0.30-roadmap.md` into an explicit execution order.
Placement does not authorize live mutation, public contracts, dependencies, or
remote operations.

## Global rules

- Measure before changing timeout, wait, retry, or process ownership.
- Do not infer operation-side polling when source inspection shows one
  synchronous Runtime evaluation.
- Keep transport, operation, renderer, and harness evidence distinguishable.
- Mutation and unknown-outcome paths never retry automatically.
- Every measurement and transition has one deterministic absolute bound.
- Public diagnostics require a stable, actionable, public-safe contract.
- Keep target IDs, endpoints, payloads, account metadata, credentials, symbols,
  and machine paths out of tracked evidence.
- Each implementation slice receives a self-contained ExecPlan and focused
  review. Do not push without explicit owner direction.
